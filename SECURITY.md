# Security

Do not post credentials, tokens, charging-card numbers, config entries, exact locations, unredacted history or raw HTTP logs in public issues.

Use the repository's **Security → Report a vulnerability** page if private vulnerability reporting is enabled. If it is unavailable, open a public issue with only a short request for a private contact channel; include no exploit details or private data. No private reporting channel is guaranteed until configured by the maintainer.

Only the latest released version receives fixes. This is an unofficial integration built on a reverse-engineered API. EnBW may change authentication or API behavior at any time.
